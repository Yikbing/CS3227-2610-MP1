# Study Tracker User Guide

Study Tracker records completed study sessions and summarizes the time spent on each module. Enter commands in the box at the bottom of the application and press Enter or **Execute**.

Dates use the `YYYY-MM-DD` format and durations are positive whole numbers of minutes.

## Adding a study session

`add m/MODULE t/TOPIC d/MINUTES on/DATE [n/NOTES]`

Example:

`add m/CS3227 t/Command parsing d/90 on/2026-08-17 n/Implemented parser tests`

## Listing sessions

`list`

## Editing a session

`edit INDEX [m/MODULE] [t/TOPIC] [d/MINUTES] [on/DATE] [n/NOTES]`

Only supplied fields are changed. Use an empty notes value, such as `n/`, to remove existing notes.

Example: `edit 2 d/120 n/Reviewed tutorial questions`

## Deleting a session

`delete INDEX`

The index refers to the number shown by `list`.

## Finding sessions

`find KEYWORD`

This searches modules, topics, and notes without regard to letter case.

## Filtering sessions

`filter [m/MODULE] [from/DATE] [to/DATE]`

At least one filter must be supplied. Date boundaries are inclusive.

Examples:

- `filter m/CS3227`
- `filter from/2026-08-01 to/2026-08-31`

## Viewing statistics

`stats`

Displays the number of sessions, total study time, and study time grouped by module.

## Other commands

- `help`: displays all command formats.
- `exit`: closes the application.

## Saved data

Changes are saved automatically to `data/sessions.txt`. If the file does not yet exist, Study Tracker starts with an empty history.

Do not edit this file while the application is running. If the file is malformed, Study Tracker reports the problem and opens an empty list rather than terminating unexpectedly.
